Data engineering

03

Spotify Pipeline — Azure + Databricks

A governed Bronze, Silver and Gold pipeline that turns raw source data into an analytics-ready warehouse.

  • Azure Data Factory
  • Databricks
  • Delta Live Tables
  • CI/CD
Read case study +

Challenge Raw Spotify source data in Azure SQL needed to become a governed, analytics-ready warehouse without manual reprocessing on every load.

Approach Built a Bronze, Silver and Gold pipeline using Azure Data Factory for incremental CDC ingestion into ADLS Gen2, metadata-driven Jinja SQL, Delta Live Tables, SCD handling, Unity Catalog governance and Databricks Asset Bundles for CI/CD.

Outcome A star-schema warehouse with parameterised, reusable pipelines and automated development-to-production promotion.
