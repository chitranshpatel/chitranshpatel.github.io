# Chitransh Patel Portfolio

A lightweight, static portfolio for data analyst, data integrity, retail data, business intelligence and junior data engineering opportunities in Australia.

## Run locally

Open `index.html` in a browser, or serve this directory with any static-file server. No package install, build step or backend is required.

## Update content

- Edit page content and metadata in `index.html`.
- Adjust visual design in `assets/styles.css`.
- Keep interactions small and dependency-free in `assets/script.js`.
- Add a résumé link only when a current PDF is ready to publish.

## Deploy to GitHub Pages

This repository deploys as a static site. Commit and push changes to the branch configured in GitHub Pages (currently `main`); GitHub Pages serves the root `index.html`. No deployment setting changes are required.
